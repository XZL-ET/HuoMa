## 一、ECS 应用服务器

**入口**：阿里云控制台 → 弹性计算 → 云服务器 ECS → 创建实例

| 选项 | 选什么 | 说明 |
|------|--------|------|
| **计费方式** | **包年包月** | 比按量便宜 15% |
| **地域** | 选择离你最近的（如华东 1 杭州、华东 2 上海） | |
| **可用区** | 随机分配即可 | 单机不需要挑 |
| **实例规格** | **ecs.c6.xlarge**（4 vCPU · 8 GiB） | 计算型，性价比高 |
| **镜像** | **Alibaba Cloud Linux 3** 或 CentOS 7.9 | |
| **系统盘** | ESSD 40 GiB · PL0 | ¥0.6/GiB/月 |
| **数据盘** | 不用买 | 数据在 RDS 上 |
| **网络** | 默认 VPC + 默认交换机 | 新建也行 |
| **公网 IP** | **不勾选** | 后面单独买 EIP 绑定 |
| **安全组** | 新建 → 只放行 22（你本机 IP）、443（0.0.0.0/0）、80（0.0.0.0/0） | |
| **登录凭证** | 密钥对（推荐）或密码 | |
| **实例名称** | `huoma-prod` | |
| **购买时长** | **1 年**（便宜 25%） | |

**价格**：约 ¥280/月，1 年 ¥3,360

## 二、弹性公网 IP（EIP）

**入口**：弹性公网 IP → 申请弹性公网 IP

| 选项 | 选什么 |
|------|--------|
| **计费方式** | **按流量计费** |
| **带宽峰值** | 10 Mbps（只设上限，不按带宽收费） |

**价格**：IP 保有费 ¥0.02/小时（约 ¥15/月）+ 流量 ¥0.8/GB

## 五、OSS 对象存储

**入口**：对象存储 OSS → 创建 Bucket

| 选项 | 选什么 |
|------|--------|
| **Bucket 名称** | `huoma-backups` |
| **地域** | 和 ECS 同地域 |
| **存储类型** | 标准存储 |
| **读写权限** | **私有** |
| **版本控制** | 不开 |

创建后：
1. Bucket 列表 → `huoma-backups` → 生命周期 → 创建规则
   - 前缀：`db/`
   - 过期天数：30 天（自动清理旧备份）

2. ECS 上安装 ossutil 工具：

```bash
# 在 ECS 上执行
wget https://gosspublic.alicdn.com/ossutil/1.7.19/ossutil64
chmod 755 ossutil64
./ossutil64 config  # 输入 AccessKey ID 和 Secret
```

**价格**：¥3-5/月（20 GiB 存储 + 少量请求费）

## 六、SSL 证书

**入口**：SSL 证书 → 购买证书 → 免费证书（DV）

| 选项 | 选什么 |
|------|--------|
| **证书类型** | 免费 DV 单域名 |
| **域名** | `huoma.your-domain.com` |

验证域名所有权（DNS 验证或文件验证）→ 下载 **Nginx 版本** → 上传到 ECS：

```bash
# 在 ECS 上执行
mkdir -p /etc/nginx/ssl
# 把 fullchain.pem 和 privkey.pem 放到这个目录
```

## 八、买完后的顺序

```
第 1 步：ECS 开机 → 用密钥登录 → yum update
         ├─ 装 JDK 17：yum install java-17-openjdk
         ├─ 装 Nginx：yum install nginx
         └─ 装 ossutil（备份用）

第 2 步：RDS 建库建账号 → 执行 schema.sql
         └─ 白名单加 ECS 内网 IP

第 3 步：Redis → 设密码 → 白名单加 ECS 内网 IP

第 4 步：ECS 上创建 huoma.env 环境变量文件
         └─ 填入 RDS/Redis/企微 的连接信息

第 5 步：部署应用
         ├─ 改 deploy.sh 的 SERVER_IP
         ├─ ./deploy.sh prod
         └─ curl https://域名/actuator/health → 200 ✅

第 6 步：配 Nginx + SSL 证书
         ├─ 证书上传到 /etc/nginx/ssl/
         ├─ nginx.conf 改域名
         └─ nginx -t && systemctl restart nginx

第 7 步：企微后台 → 回调 URL 改成 https://你的域名/api/wecom/callback
         └─ 验证通过 ✅

第 8 步：配备份 crontab
         └─ 每天 3:00 mysqldump → OSS

第 9 步：旧机改 staging
         └─ systemd 改 -Dspring.profiles.active=staging
```
