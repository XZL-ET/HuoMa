# 活码创建 — 学校人数自动配置接待员

**日期:** 2026-06-14
**状态:** 已批准

## 背景

创建活码时，运营人员需要根据学校学生人数手动估算需要多少个接待员。改为输入学生人数后系统自动计算并配置。

## 规则

| 项目 | 值 |
|------|-----|
| 比例 | 每 120 学生 → 1 接待员 |
| 最小 | 1 人 |
| 最大 | 100 人 |
| 计算公式 | `need = max(1, min(100, ceil(studentCount / 120)))` |
| 选取方式 | 从全局池自动选取，排除已选服务老师 |

## 改动范围

### 1. 数据库 / 实体
- `qr_code` 表新增 `student_count INT NULL` 列
- `QrCode.java` 新增 `studentCount` 字段

### 2. DTO
- `QrCodeCreateRequest.java` 新增 `studentCount` 字段

### 3. 前端 `create.html`
- 在员工配置区新增「学校人数」输入框
- 输入后实时显示将自动配置的接待员数量预览
- 如果填了学校人数，initialAgentCount 自动由公式计算；否则保持用户手动指定

### 4. 服务层 `QrCodeService.create()`
- 若 `req.studentCount > 0`，用公式算 `initialAgentCount`，覆盖前端传值
- 现有 `bindAgents()` 无需改动：选服务老师 → 不够的从全局池自动补齐

## 示例

| 学生数 | 计算 | 需要接待员总数 | 1个服务老师占位后自动补齐 |
|--------|------|---------------|--------------------------|
| 50 | ceil(50/120)=1 → max(1,1)=1 | 1 | 0（服务老师已占） |
| 600 | ceil(600/120)=5 | 5 | 4 |
| 3000 | ceil(3000/120)=25 | 25 | 24 |
| 20000 | ceil(20000/120)=167 → min(100,167)=100 | 100 | 99 |
