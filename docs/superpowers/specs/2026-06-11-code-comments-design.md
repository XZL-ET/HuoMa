# 项目全面注释方案设计

## 概述

为整个 HuoMa（活码）项目添加详尽的中文注释，覆盖 Java 源码、Thymeleaf HTML 模板、配置文件和 SQL 脚本，共计 62 个文件。

## 目标

- 所有 public 类/方法含完整 Javadoc（`@param`、`@return`、`@throws`）
- 所有实体字段含字段级注释
- 关键业务逻辑含内联解释（"做什么"+"为什么"）
- 配置文件含配置项说明
- 注释语言：中文（变量/方法名保持英文）

## 注释规范

### Java 文件

**类注释：**
```java
/**
 * 类的职责描述（一句话概括）
 *
 * <p>详细说明（如有必要）
 *
 * @author Bookstore Dev
 * @since 1.0
 */
```

**方法注释：**
```java
/**
 * 方法功能描述
 *
 * @param paramName 参数含义
 * @return 返回值含义
 * @throws RuntimeException 什么情况下抛出
 */
```

**字段注释：**
```java
/** 字段含义，特殊值或枚举值需说明 */
private String fieldName;
```

**内联注释：**
```java
// 1. 步骤一：做什么 + 为什么这么做
// 2. 步骤二：...
// 注意：关键边界条件说明
```

### HTML 模板

```html
<!-- 区块说明：功能 + 绑定数据 -->
```

### 配置文件

- **YAML**：`# 配置项含义`
- **XML**：`<!-- 配置说明 -->`
- **SQL**：`-- 表/字段说明`

## 性能影响

Java 编译器在生成 `.class` 字节码时丢弃所有注释。部署到服务器的 `.jar` 包不含注释源码，运行时性能零影响。HTML 注释增加字节数可忽略（gzip 压缩后微乎其微）。

## 分批执行计划

| 批次 | 层级 | 文件数 | 注释重点 |
|------|------|--------|----------|
| 1 | Entity | 11 | 类职责、字段含义、枚举值、JPA 关联 |
| 2 | Repository | 11 | 查询方法用途、参数含义、返回结果 |
| 3 | Service | 8 | 完整 Javadoc、核心逻辑注释、异常说明 |
| 4 | Controller | 6 | 端点功能、请求参数、视图返回 |
| 5 | WeCom + Worker | 8 | API 调用说明、回调处理、定时任务逻辑 |
| 6 | Config / DTO / App | 5 | 配置项说明、Bean 用途、DTO 字段 |
| 7 | HTML 模板 | 10 | 区块功能、Thymeleaf 变量、表单字段 |
| 8 | 配置 / SQL | 3 | 配置项、表字段、索引 |

## 质量标准

- 每批完成后核对风格一致性
- 避免废话注释（如 `// 设置名称` 对应 `setName()`）
- 重点解释业务含义和设计决策，不重复代码表面含义
- 注释与代码同步 — 不写过期信息

## 技术栈

- Java 17+ / Spring Boot 3
- Spring Data JPA / Redis / Thymeleaf
- 企业微信（WeCom）API 集成
- Maven 构建
